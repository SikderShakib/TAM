# TAM — গরু সমিতি

২৫ জন সদস্য, প্রতি মাসে ৫০০ টাকা, ১২ মাস (নভেম্বর ২০২৬ – অক্টোবর ২০২৭)।
জনপ্রতি মোট ৬,০০০ টাকা, লক্ষ্য ১,৫০,০০০ টাকা।

## সাইটে যা আছে
- সদস্য যোগ / এডিট / মুছুন
- প্রতি মাসের ঘরে ক্লিক করে ৫০০ টাকা জমা টিক দেওয়া
- প্রত্যেকের মোট জমা, বাকি, মোট ফান্ড, লক্ষ্যের অগ্রগতি
- ব্যাকআপ ডাউনলোড / ইমপোর্ট (JSON)

## লগইন ও ভূমিকা
- Admin: সব এডিট করতে পারে, টিমের role বদলাতে পারে
- Viewer: শুধু দেখতে পারে, এডিট করতে পারে না
- Pending: নতুন সাইন আপ প্রথমে Pending থাকে, Admin role না দিলে কিছু দেখতে পারে না
